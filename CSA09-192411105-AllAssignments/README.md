## How to compile and run

Install a JDK and verify it in the VS Code terminal:

```bash
java -version
javac -version
```

Open the required task folder in VS Code. For a simple Java program:

```bash
javac Main.java
java Main
```

Use the actual Java filename in place of `Main.java`. For programs with multiple classes or external JDBC drivers, follow the task's requirements and include the required libraries.
